# Specimen & Signal

Viral videos made with Claude Opus 5.5, with the prompts behind them. Watch it, copy the prompt, paste it into Claude Opus 5.5 and run it.

**Live site:** https://specimen-and-signal.vercel.app

![Viral Opus 5.5 videos, with the prompts behind them](og.jpg)

- **11 prompts from the creators**, copied word for word from their public posts on X and checked against the source.
- **12 starter prompts** for viral videos whose creators didn't post a short prompt. These are ours. Where a creator shared a long prompt, the card links to it.

Posts were found with Grok (X and web search) on 28 Sep 2026 and each one was checked: the post exists, it has a video, and quoted prompts match the original text. Views are as of that date.

## Run locally

It's a single static page with no build step. Videos load through X's official embed.

```bash
python3 -m http.server 8000
```
