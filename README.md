# Specimen & Signal

Viral videos made with Claude Opus 5.5, with the prompts behind them. Watch it, copy the prompt, paste it into Claude Opus 5.5 and run it.

**Live site:** https://specimen-and-signal.vercel.app

![Viral Opus 5.5 videos, with the prompts behind them](og.jpg)

- **200 videos** in five types: motion design (27), launch videos (25), explainers (24), interactive 3D (76), films & music (48).
- **28 prompts from the creators**, copied word for word from their public posts on X and checked against the source.
- **172 starter prompts** for videos whose creators didn't post a short prompt. These are ours. Where a creator shared a long prompt, the card links to it.

Posts were found with Grok (X and web search) and with community lists of Opus 5.5 videos, then each one was checked on X on 29 Sep 2026: the post exists, it has a video and says it was made with Opus 5.5, and quoted prompts match the original text word for word. Views are as of that date.

Community lists that helped find posts: [yihui-dev/awesome-opus5-5-videos](https://github.com/yihui-dev/awesome-opus5-5-videos), [athemeroy/awesome-opus-5-5-videos](https://github.com/athemeroy/awesome-opus-5-5-videos), [opusvideo/awesome-claude-video](https://github.com/opusvideo/awesome-claude-video), [chuspeeism/awesome-opus-5-5-videos](https://github.com/chuspeeism/awesome-opus-5-5-videos), [zhuyansen/awesome-opus-5.5-video](https://github.com/zhuyansen/awesome-opus-5.5-video), [BeatAPI/awesome-opus-5-5-videos](https://github.com/BeatAPI/awesome-opus-5-5-videos), [coolbat/awesome-opus-5.5-usecase](https://github.com/coolbat/awesome-opus-5.5-usecase), [X-RayLuan/awesome-opus-5-5-video-prompts](https://github.com/X-RayLuan/awesome-opus-5-5-video-prompts), [Li-Evan/awesome-opus-5.5-video-prompts](https://github.com/Li-Evan/awesome-opus-5.5-video-prompts), [RealBetterToken/awesome-opus-5.5-video-prompts](https://github.com/RealBetterToken/awesome-opus-5.5-video-prompts).

## Run locally

It's a single static page with no build step. Videos play inline, streamed from X's own video servers (the page sends no referrer), and filter chips group them by type.

```bash
python3 -m http.server 8000
```
